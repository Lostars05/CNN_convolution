01 · OVERVIEW

CNN이란?

CNN(Convolutional Neural Network)은 이미지의 채널·높이·너비 구조를 유지하면서 국소 영역의 패턴을 학습하는 신경망이다. 작은 필터를 입력 위에서 이동시키며 특징을 추출하고, 필터의 가중치를 여러 위치에서 공유한다.

국소 연결

입력 전체가 아니라 작은 영역을 대상으로 연산해 주변 픽셀의 관계를 학습한다.

가중치 공유

같은 필터를 여러 위치에 적용하므로 위치마다 별도의 가중치를 둘 필요가 없다.

특징 학습

초기 계층은 간단한 국소 패턴을, 깊은 계층은 이를 조합한 표현을 학습할 수 있다.

완전연결 계층은 입력을 평탄화해 공간적 이웃 관계를 구조로 활용하지 않지만, CNN은 국소 연결과 가중치 공유를 이용한다.
02 · TERMINOLOGY

주요 용어

용어 정의
입력(Input) 모델에 전달되는 이미지 데이터. 일반적으로 채널(C), 높이(H), 너비(W)의 구조를 가진다.
커널 / 필터(Kernel / Filter) 입력의 작은 영역과 원소별 곱셈·합산을 수행하는 학습 가능한 가중치 묶음.
특징 맵(Feature Map) 필터가 각 위치에서 반응한 결과를 모아 만든 출력 맵.
채널(Channel) 입력 또는 출력 데이터의 깊이 차원. RGB 이미지라면 입력 채널은 3개다.
편향(Bias) 필터 연산 결과에 더하는 값. 일반적으로 출력 채널마다 하나씩 둔다.
패딩(Padding) 입력의 가장자리에 값을 추가하는 처리. 제로 패딩은 0으로 채운다.
스트라이드(Stride) 필터가 입력 위에서 한 번 이동할 때 이동하는 간격.
풀링(Pooling) 작은 영역을 대표값으로 요약해 특징 맵의 공간 크기를 줄이는 연산.
배치(Batch) 한 번의 학습 반복에서 함께 처리하는 입력 표본의 묶음.
03 · HYPERPARAMETERS

주요 하이퍼파라미터

하이퍼파라미터는 학습 절차와 모델 크기를 정하는 값이며, 가중치처럼 역전파로 직접 갱신하는 값과 구분한다.

항목 의미 변경했을 때 고려할 점
kernel_size 필터의 높이와 너비 큰 커널은 더 넓은 영역을 한 번에 본다.
filters(Keras), out_channels(Pytorch) 사용하는 필터의 개수 필터 수만큼 출력 채널이 생성된다.
strides 필터의 이동 간격 같은 입력과 필터라면 클수록 출력 공간 크기는 작아진다.
padding 입력 가장자리에 덧붙이는 크기 출력 크기를 조정하고 가장자리 정보 사용을 돕는다.
batch_size 한 번에 처리하는 표본 수 메모리 사용량과 기울기 추정의 변동에 영향을 준다.
learning_rate 매개변수 갱신 크기를 조절하는 값 너무 크면 진동·발산, 너무 작으면 수렴이 느릴 수 있다.
epochs 전체 훈련 데이터를 한 번 학습한 단위 너무 오래 학습하면 과적합 위험이 커질 수 있다.
weight_decay 정규화 강도(예: λ) 너무 강하면 훈련 데이터도 충분히 학습하지 못할 수 있다.
출력 크기 공식
O = ⌊(I + 2P − F) / S⌋ + 1

높이와 너비에 각각 적용한다. I: 입력 크기, O: 출력 크기, F: 필터, P: 패딩, S: 스트라이드. (dilation=1인 경우)

04 · GENERALIZATION

과적합과 정규화

과적합(Overfitting)은 훈련 데이터에는 잘 맞지만 새로운 데이터에서는 성능이 떨어지는 상태다. 훈련 성능과 검증 성능의 차이를 함께 관찰해 진단한다.

과적합에 영향을 미치는 요인

과적합은 데이터 양 뿐 아니라 잡음, 데이터 누수, 학습 시간 등의 영향도 받는다.

대응 방향

모델 크기, 데이터, 학습 시간과 정규화 강도를 검증 성능을 기준으로 조정한다.

대표적인 정규화 방법

방법 핵심 원리 유의점
L2 정규화 / 가중치 감소 데이터 손실에 가중치 제곱합의 페널티를 더한다.
L_total = L_data + (λ/2)Σw² 		λ가 클수록 가중치를 강하게 제한한다. 너무 크면 과소적합이 생길 수 있다.
Dropout 훈련 중 확률 p로 일부 활성화값을 0으로 만든다. 추론 시에는 마스킹과 추가 스케일 보정을 적용하지 않는다. Inverted Dropout은 살아남은 값을 1/(1-p)배 한다.
Data Augmentation 훈련 이미지에 변환을 적용해 데이터 다양성을 늘린다. 레이블 의미가 유지되는 변환을 선택해야 한다.
Batch Normalization 미니배치 통계로 정규화한 뒤 학습 가능한 γ, β로 스케일과 이동을 조정한다. 훈련과 추론에서 사용하는 통계가 다르므로 모드를 구분한다.
정규화는 무조건 강하게 적용하는 것이 목표가 아니다. 검증 성능을 확인하면서 과적합 완화와 과소적합 사이의 균형을 맞춘다.
