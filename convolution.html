CONVOLUTION

합성곱 연산 과정

입력 행렬 위에서 필터가 이동하며 출력값을 만드는 과정을 숫자로 확인
(2차원 단일 채널 예시)

01

입력 데이터와 필터 준비

입력 이미지의 일부 영역에 작은 필터(커널)를 적용한다. 필터의 각 원소는 학습되는 가중치이며, 필터의 계수는 위치가 달라도 공유한다.

Input · 5 × 5

입력 행렬 X

Kernel · 3 × 3

필터 W
일반적인 CNN 구현에서는 커널을 뒤집지 않는 상호상관 연산을 합성곱이라고 부른다.
02

한 위치에서 원소별 곱셈

필터와 입력의 현재 영역을 같은 크기로 맞춘다. 대응하는 위치의 원소끼리 곱한다.

현재 선택된 입력 영역

곱셈 결과

출력값 = 곱셈 결과의 합
03

곱셈 결과를 모두 더해 출력값 계산

현재 위치의 출력값 하나는 입력 패치와 필터의 원소별 곱을 모두 더한 값이다. 이후 편향이 있다면 해당 출력 채널의 편향을 더한다.

현재 위치의 합성곱 출력
0

필터 이동 위치

행 1 · 열 1

1 / 9 위치
04

필터를 이동하며 특징 맵 생성

같은 필터를 오른쪽으로 이동시키고, 한 행이 끝나면 다음 행으로 이동한다. 모든 위치에서 계산한 출력값을 모으면 하나의 특징 맵(Feature Map)이 된다.

Feature Map · 3 × 3

아직 계산하지 않은 위치는 · 로 표시
이 예제는 입력 5×5, 필터 3×3, 패딩 0, 스트라이드 1이므로 출력은 3×3이다.
05

패딩과 스트라이드에 따른 출력 크기

패딩은 입력 주변을 확장하고, 스트라이드는 필터의 이동 간격을 정한다. 두 값은 출력의 높이와 너비에 영향을 준다.

O = ⌊(I + 2P − F) / S⌋ + 1

필터가 한 번에 이동하는 칸 수

가장자리에 추가하는 칸 수

출력 크기: 3 × 3

06

채널과 여러 필터

컬러 이미지처럼 입력 채널이 여러 개라면 하나의 필터는 모든 입력 채널을 함께 처리한다. 채널 방향의 계산 결과를 합산해 하나의 출력 채널을 만든다.

입력

C × H × W

C개의 입력 채널

필터 가중치

FN × C × FH × FW

필터마다 모든 입력 채널을 포함

출력

FN × OH × OW

필터 개수 FN만큼 출력 채널 생성

배치까지 포함한 일반적인 텐서 형상 표기는 (N, C, H, W)이다. N은 배치 크기다.
07

활성화 함수와 풀링

합성곱 결과에 ReLU와 같은 활성화 함수를 적용해 비선형성을 추가할 수 있다. 풀링은 작은 영역의 대표값을 선택하거나 평균해 공간 크기를 줄인다.

ReLU

ReLU(x) = max(0, x)

음수는 0으로, 양수는 그대로 전달한다.

Max Pooling 예시

[ 1 3 ]
[ 2 4 ]　→　4

2×2 영역에서 가장 큰 값을 선택한다. 보통 학습할 가중치는 없으며 채널 수는 유지한다.

08

CNN 연산 흐름 정리

Input → Convolution → Bias → ReLU → Pooling → Flatten → Classifier

합성곱 계층은 이미지의 국소 특징을 추출하고, 활성화 함수와 풀링을 거친 특징은 분류기 등에 전달되어 최종 예측에 사용된다. 실제 네트워크의 구성과 계층 순서는 설계에 따라 달라질 수 있다.
